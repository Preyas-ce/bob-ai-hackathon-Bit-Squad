# Source Code

This folder contains the source code for the Defence Threat Intelligence dashboard.

## Structure

* `pages/` — Main application pages such as the dashboard.
* `components/` — Reusable UI components such as incident cards and the investigation drawer.
* `types/` — TypeScript data structures used by the application.
* `utils/` — Utility functions such as the explainable threat score.
* `App.tsx` — Main application component.

The project is built using React and TypeScript with Vite and Tailwind CSS.
